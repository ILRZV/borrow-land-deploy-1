# BorrowLand

### Docker

##### Installation
- Docker: https://docs.docker.com/desktop/windows/install/ (attention to system requirements)
- Make: https://stackoverflow.com/questions/32127524/how-to-install-and-use-make-in-windows

##### Usage
- Development: docker-compose up 
- Development with packages or pull from GitHub: ctrl+c, docker-compose build
- Frontend: http://localhost/
- Backend: http://localhost/api
- Makefile: $ make clear
